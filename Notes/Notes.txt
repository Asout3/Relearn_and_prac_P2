deposit():
      Input: nothing through typing But receive native eth by direct calling.
      Access: anyone.
      Return: nothing.

      DONE T1: pass -> make sure every thing works normally.
      DONE T2: pass -> make sure the receive works normally.
      DONE T3: Input: transfer 0 eth -> pass. (check by the event).
      DONE T4: Input: transfer type(uint256).max -> pass. check through balanceOf and event.

      DONE emits an event: Deposit(msg.sender, msg.value);

withdraw(uint256 wad):
      Input: wad is the amount of eth that we want to withdraw.
      Access: anyone.
      Return: 0.

      DONE T1: pass -> make sure every thing works normally.
      DONE T2: balanceOf[msg.sender] < wad -> reverts with revert so it is going to be normal revert.
      DONE T3: Input: wed == 0 -> pass.
      DONE T4: Inpu: wed == 0 on non owner -> pass.
      DONE T4: Input wed == type(uint256).max -> pass.
      DONE T5: Input wed == exactly what he owns -> pass

      DONE emits an event: Withdrawal(msg.sender, wad);

approve(address guy, uint256 wad):
      Input: the will be approved address(guy) and the amount of weth is approven(was)
      Access: anyone
      Return: true.

      DONE T1: pass -> make sure it works.
      DONE T2: Input: zero address -> pass. 
      DONE T3: Input: zero address and 0 -> pass.
      DONE T4: Input: zero address and type(uint256).max -> pass.
      DONE T5: Input: more than the approver have -> pass.
      DONE T6: Input: type(uint256).max -> pass.

      DONE emits an event Approval(msg.sender, guy, wad);

transfer(address dst, uint256 wad):
      Input: destination address and amount.
      Access: anyone.
      Return: True.

      T1: pass -> make sure it works.
      T2: Input: wad == more than it have -> revert.
      T3: Input: wad == type(uint256).max -> revert.
      T4: Input: dst == zero address -> pass.
      T5: Input: wad == zero -> pass.

      emits an event Transfer(src, dst, wad);

transferFrom(address src, address dst, uint256 wad): 
      Input: the source address, the destination address and the amount of token we send.
      Access: anyone.
      Return: True.

      T1: pass(doesn't satisfy the if) -> make sure every thing works.
      T2: pass(does satisfy the if) -> make sure every thing works.
      T2: balanceOf[src] < wad -> reverts.
      T3: Input: src == zero address -> reverts.
      T4: Input: src && dst == zero address -> reverts.
      T5: Input: dst == zero address -> pass.
      T6: Input: wad == zero -> zero.


      emits an event Transfer(src, dst, wad);
